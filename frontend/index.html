🤖 Full Automation Setup

Step 1 — Install the Chrome Extension (once per profile)

The extension lives in Backend/extension/. Load it into each AdsPower Chrome profile using Load Unpacked (chrome://extensions → Developer mode ON → Load unpacked → select the extension/ folder).

After the first launch of each profile, the system also tries to auto-copy the extension files into the AdsPower profile directory automatically. You still need to click Load Unpacked once to register it with Chrome.

ONE-TIME SETUP ✓ Auto-installed on subsequent launches
Step 2 — Set the Profile ID in the Extension Popup

After loading the extension, click its icon in the Chrome toolbar.
Paste your AdsPower Profile ID (the short alphanumeric ID from the AdsPower profile list) and click Save & Connect.

The popup will show ● Connected when the extension has a live WebSocket connection to your Django server. From this point the extension is fully autonomous — it sends messages, reports results, and scans for incoming messages all by itself.

Step 3 — Import Contacts via Admin Portal

Go to Admin → Contacts → Import CSV. Upload a CSV with columns: name, phone_number, email, tags, notes.

Every contact in the CSV will be created instantly. If you have an Auto-Send campaign running (see Step 4), each new contact triggers an immediate personalized message — no clicks needed.

Open Admin → Contacts
Step 4 — Create an Auto-Send Campaign

In Messaging → Campaigns → New Campaign, tick the 🤖 Auto-Send checkbox and set status to Running.

From now on: you import contacts → contacts are saved → signal fires → AI personalizes the message → task is pushed via WebSocket to the extension → extension sends the message in WhatsApp Web → result is saved in Message Logs. Zero human clicks required.

✓ Fully automated AI PERSONALIZED
Step 5 — Enable AI (optional)

Add your Claude API key to .env: 

CLAUDE_API_KEY=sk-ant-api03-your-key-here

With AI enabled: outbound messages are rewritten to sound natural for each contact (not just {name} replacement), and incoming replies get smart AI-generated responses automatically. Without a key, the system still works — it just uses plain template substitution.

How it all connects
You import contacts (Admin Portal CSV)
    ↓  Django signal fires immediately
    ↓  AI personalizes the message (Claude API)
    ↓  Task pushed via WebSocket
Chrome Extension (inside AdsPower profile)
    ↓  Navigates WhatsApp Web to /send?phone=...&text=...
    ↓  Clicks Send button
WhatsApp Web → Contact's phone 📱
    ↓  (15 s later) Extension scans for replies
    ↓  Sends incoming messages to Django via WebSocket
    ↓  AI generates reply → extension sends it back
Fully automated loop — no human needed

🕐 Campaign Scheduler — Run Campaigns Automatically (No Redis Needed)

Set a Scheduled At date/time on a campaign, then run this command every 5 minutes via Windows Task Scheduler to dispatch it automatically:

cd C:\Users\admin\Desktop\Backend
.\venv\Scripts\activate
python manage.py run_scheduled_campaigns

Windows Task Scheduler setup:

  1. Open Task Scheduler (search in Start)
  2. Click Create Basic Task
  3. Trigger: Daily → Repeat every 5 minutes
  4. Action: Start a program
  5. Program: C:\Users\admin\Desktop\Backend\venv\Scripts\python.exe
  6. Arguments: manage.py run_scheduled_campaigns
  7. Start in: C:\Users\admin\Desktop\Backend
